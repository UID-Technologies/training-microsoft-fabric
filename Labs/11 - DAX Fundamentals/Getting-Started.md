# Getting started — Module 11 (DAX & KPIs)

1. Read **[Labs/Getting-Started.md](../Getting-Started.md)** (Fabric capacity).  
2. Open **[Lab 01](./Lab_01_CRM_DAX_KPIs/Lab%2001%20-%20CRM%20DAX%20fundamentals%20and%20business%20KPIs.md)**.  
3. Sign in at **https://app.fabric.microsoft.com** — this lab uses **Power BI on the web**, not Power BI Desktop.  
4. Create standalone workspace **`M11_L01_<id>`**, lakehouse **`lh_m11_dax`**, semantic model **`sm_m11_dax_<id>`**.  
5. Finish **Part A Step A3** (nine relationships, no ambiguous links) before any DAX in Part B.  
6. Import data only from **`Lab_01_CRM_DAX_KPIs/data/`**.  
7. Time intelligence is **Part D** of this lab; reporting dashboards are **[Module 12](../12%20-%20Power%20BI%20Reporting/)**.
